QuickBite – Canteen Pre-Ordering System

QuickBite is a full-stack web application built with the MERN stack (MongoDB, Express.js, React.js, Node.js) that lets users browse the canteen menu, add items to a cart, and place orders in advance. It reduces waiting time at the canteen, and gives admins a dashboard to manage food items and incoming orders.

🔗 Live Demo: canteen-preordering-system.vercel.app

Features
👤 User
Register and log in with secure authentication
Browse the canteen menu
Add / remove items from the cart
Place orders in advance
Track your orders

🛠️ Admin
Separate admin panel
Add, update, and delete food items
View and manage all incoming orders
Update order status


🧰 Tech Stack
Layer	Technology
Frontend - React.js
Admin Panel -	React.js
Backend -	Node.js, Express.js
Database	- MongoDB (Mongoose)
Auth	- JSON Web Tokens (JWT)
Deployment	- Vercel, Render
